Semester 2 — SKIL2

Web Application — KVV Rauw

Context

This team project in SKIL2 focused on building a complete web application for the football club KVV Rauw. Another group created the analysis; our team translated the requirements into a working application with an emphasis on usability and management.

What I Built

I helped build the full agenda page, outstanding payments for parents, agenda and match seeders, absence registration, image slots in agenda items and the carpool workflow for registration and management.

Technologies Used

  • HTML, CSS and JavaScript
  • Database seeders
  • Team delivery based on an existing analysis
  • Management and content screens for a sports club

My Contribution

I took responsibility for several key parts: the agenda, the carpool flow, the payment overviews and the visual refinement of the management pages. I also coordinated the logic with teammates so the different parts worked consistently.

What I Learned

  • Breaking complex functionality into manageable tasks
  • Working in a team with shared code and requirements
  • Aligning UI choices with real users and admin roles

Packet Plague

SKILL 1 — Semester 2

In SKILL 1 during semester 2, teams were tasked with building an educational experience for secondary school visitors at a technology fair. Our team created Packet Plague — an interactive game where players remove a virus from a network by solving binary conversion puzzles. The goal was to make networking concepts accessible and engaging for students with no technical background.

My contribution
  • Poster design
  • Full game UI
  • Presentation stand layout

What I Learned

  • Designing for a non-technical audience requires simplicity and clear visual feedback
  • Combining game mechanics with an educational goal
  • Delivering a polished product under a public presentation deadline
